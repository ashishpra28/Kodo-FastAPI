This repository contains my hands-on learning journey with **FastAPI**, focused on building modern, scalable APIs for **Generative AI and Agentic AI applications**.

### 🚀 Topics Covered

- FastAPI fundamentals
- REST APIs
- Routing & endpoints
- Request & response handling
- Pydantic models
- Dependency Injection
- Middleware
- Application lifecycle
- Authentication & authorization
- API documentation with OpenAPI / Swagger
- Error handling
- Async programming
- Database integration
- Deployment
- Building APIs for GenAI applications

### 🛠️ Tech Stack

- **Python**
- **FastAPI**
- **Uvicorn**
- **Pydantic**
- **REST API**
- **OpenAPI / Swagger**
- **uv** — Python package & project manager

### 🎯 Goal

The goal of this repository is to develop strong backend development skills and learn how to build **production-ready APIs for AI/ML and Agentic AI systems**.
